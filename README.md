# Area Counter

Плагин SketchUp 2024 для автоматизации математических расчётов прямо в модели —
первый инструмент в автоматизации архитектурного процесса.

Версия 0.2 · лицензия [Apache 2.0](LICENSE) · © 2026 B&A community

## Панель

| # | Кнопка | Состояние |
|---|--------|-----------|
| 1 | Площадь верхних граней | работает |
| 2 | Объём выделенного | заглушка |
| 3 | Длины и периметр | заглушка |
| 4 | Спецификация | заглушка |
| 5 | Экспорт расчёта | заглушка |

Рабочая кнопка суммирует площадь верхних горизонтальных граней у всех выделенных
групп и компонентов и показывает результат в квадратных метрах. Заглушки
нажимаются и сообщают, что инструмент не реализован.

Чтобы включить любую из них — замените `action: :stub` в `TOOLBAR_BUTTONS`
([src/area_counter/toolbar.rb](src/area_counter/toolbar.rb)) на имя нового метода
модуля и добавьте сам метод. Меню строится из того же списка.

## Установка

SketchUp → **Расширения → Менеджер расширений → Установить расширение** →
выбрать `area_counter.rbz`. Панель появится сама; вернуть её потом можно через
**Вид → Панели инструментов → Area Counter**.

## Структура

```
src/
  area_counter.rb                  регистратор расширения
  area_counter/
    main.rb                        логика расчётов + загрузка UI
    toolbar.rb                     панель инструментов и меню
    icons/                         *.svg (Windows) + *_24.png / *_16.png (фолбэк)
tools/
  build_icons.ps1                  перерисовывает PNG-фолбэки иконок
  build_rbz.ps1                    собирает src/ в area_counter.rbz
area_counter.rbz                   готовый пакет для установки
```

Пространство имён — `BACommunity::AreaCounter`.

## Сборка

```bash
powershell -ExecutionPolicy Bypass -File "tools\build_rbz.ps1"
```

Иконки перерисовываются отдельно, только если менялись формы:

```bash
powershell -ExecutionPolicy Bypass -File "tools\build_icons.ps1"
```

## Грабли

- `.rbz` — обычный ZIP, `area_counter.rb` должен лежать **в корне** архива,
  а пути внутри — через прямой слэш (см. комментарий в `build_rbz.ps1`).
- SVG-иконки понимает только Windows-версия SketchUp (2016+); на macOS нужен PDF,
  поэтому там код откатывается на PNG.
