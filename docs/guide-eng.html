area counter 1.0 — quick guide

SketchUp 2024 / 2025 / 2026 extension: floor, building and complex areas by top face or by section, a table via the clipboard, section faces in the model

1Install

SketchUp → Window → Extension Manager → Install Extension → pick area-counter-1.0-eng.rbz → restart SketchUp. A “Calculate area” button appears on the “area counter” toolbar, plus the Extensions → area counter menu. Remove any earlier test build before installing.

2Calculate

  1. Select a building, a complex or the floors themselves — groups or components.
  2. Toolbar button or Extensions → area counter → Calculate area — the results window opens.
  3. On the right, What is selected: Floors — the floors themselves, Building — floors one level down, Complex — two levels down. Each floor counts as a whole, with everything nested in it.
  4. Method: Top face — fast, by the horizontal faces at the top elevation; Section — a horizontal cut at a height above the floor bottom (1000 mm by default), area by the outer contour including facade relief and windows.

Section settings: gaps up to 20 mm between facade pieces are closed, point weld 1 mm, hidden objects are skipped, inner courtyards are not subtracted by default (“subtract courtyards” box). If the cut lands on a slab it moves 2 mm up; if a doorway breaks the facade ring, the plugin picks another height and writes it in the status.

3Table and statuses

A complex → building → floor tree with areas in m². Click a row to zoom to the object. calculated — can be trusted; caveat — calculated, but the height moved or separate pieces were found; problem — cannot be trusted, the reason is in the pill. problems only leaves the red ones, Highlight outlines the results in the viewport (Esc to turn off).

4Copy to a spreadsheet

On the right, Copy: Floors (for checking), Buildings or Complexes. The Copy button puts the table on the clipboard — press Ctrl+V in Google Sheets / Excel: columns land by themselves, numbers use a decimal point, upper-level areas are in the same rows.

5Output sections

After calculating with the “Section” method, Output sections puts a group “area counter: sections” on the AC_Sections tag into the model, with the same hierarchy. Each floor group holds one flat face along the outer contour at the cut height: click it and Entity Info shows the area. Running again replaces the floor’s previous section. Source floors are not changed; undo — Ctrl+Z.

6A single floor

Select one floor group → Extensions → area counter → Floor section… → set the cut height, gaps and courtyards → OK. The plugin builds the face and shows the area in the window.

Note. Separate section pieces (over 0.1 m²) are not included in the floor area — the status mentions them. Window settings are remembered; Reset restores the defaults. Version and authors — Extensions → area counter → About…
